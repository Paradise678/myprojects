# 通用旅行常识

## 出行准备
- 证件：身份证必带，住酒店、乘火车飞机均需；学生证、老年证可享门票优惠
- 行李：轻装出行，根据目的地气候准备衣物；建议携带充电宝、转换插头、常备药品
- 保险：长途或高风险活动建议购买旅游意外险

## 交通常识
- 高铁：提前在12306购票，凭身份证进站；节假日需提前抢票
- 飞机：建议提前2小时到机场，国内航班起飞前45分钟停止值机
- 市内：推荐使用地图APP导航，地铁+打车组合效率最高

## 住宿建议
- 位置：优先选择地铁沿线或景区附近，节省通勤时间
- 预订：节假日提前1-2个月预订，价格波动大
- 比价：多平台比价，注意是否含早餐、退改政策

## 门票与预约
- 热门景点（故宫、兵马俑、迪士尼等）需提前实名预约，部分需提前7天
- 关注官方公众号获取最新开放时间、限流政策
- 善用套票/联票可节省费用

## 安全提示
- 保管好贵重物品，人多场合注意防盗
- 不乘坐黑车，选择正规出租车或网约车
- 关注目的地天气预警，极端天气调整行程
- 记住当地急救电话120、报警110

## 省钱技巧
- 错峰出行：工作日和淡季价格明显更低
- 使用各城市旅游年卡/一卡通，常含多个景点免费或折扣
- 关注景点免票日、半价日
- 本地美食优先选择居民区小馆，性价比高于景区店
