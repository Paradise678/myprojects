# 成都旅游指南

## 城市概况
成都四川省省会，国家历史文化名城，以悠闲的生活节奏、美食和大熊猫闻名。最佳旅游季节为春秋两季（3-6月、9-11月），夏季炎热多雨，冬季湿冷少雪。

## 核心景点

### 大熊猫繁育研究基地
- 门票：55元
- 建议游览：3小时
- 世界著名的大熊猫迁地保护基地，可近距离观赏大熊猫
- 提示：早上8-10点大熊猫最活跃，建议开园即到；可乘地铁3号线转景区直通车

### 武侯祠
- 门票：50元
- 建议游览：2小时
- 纪念诸葛亮的祠堂，中国唯一君臣合祀祠庙，三国文化圣地
- 提示：红墙竹影是经典拍照点

### 宽窄巷子
- 门票：免费
- 建议游览：2小时
- 由宽巷子、窄巷子、井巷子组成的清代古街道，茶馆与小吃云集
- 提示：可体验盖碗茶、掏耳朵等老成都休闲项目

### 都江堰
- 门票：80元
- 建议游览：3小时
- 世界文化遗产，2000多年前李冰父子修建的水利工程，至今仍在使用
- 提示：可从成都乘城际高铁约30分钟到都江堰站

### 青城山
- 门票：80元（前山）
- 建议游览：半天
- 道教名山，"青城天下幽"，前山道观密集，后山自然风光更佳
- 提示：建议与都江堰安排在同一天

## 特色美食
- 火锅：成都招牌，麻辣鲜香，推荐蜀大侠、小龙坎、电台巷等
- 串串香：类似火锅但食材穿串，人均消费更低
- 担担面：红油肉臊拌面，麻辣鲜香
- 龙抄手：成都特色馄饨，皮薄馅嫩
- 夫妻肺片：麻辣凉拌牛肉牛杂，经典凉菜
- 钟水饺：甜辣口味水饺，成都独有风味

## 交通建议
- 市内交通：地铁覆盖主要景点，景区间可用打车或景区直通车
- 都江堰/青城山：成都犀浦站乘城际高铁，约30分钟
- 大熊猫基地：地铁3号线熊猫大道站，转景区直通车或打车
