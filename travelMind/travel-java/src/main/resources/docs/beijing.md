# 北京旅游指南

## 城市概况
北京是中国首都，国家政治、文化中心，拥有3000多年建城史和800多年建都史。最佳旅游季节为秋季（9-11月），天高气爽；春季（4-5月）可赏花。冬季寒冷但可体验冰雪和庙会。

## 核心景点

### 故宫博物院
- 门票：旺季60元（4-10月），淡季40元（11-3月）
- 建议游览：3-4小时
- 世界上现存规模最大、保存最完整的木质结构古建筑群
- 提示：需提前在官网实名预约，周一闭馆；珍宝馆、钟表馆需另购10元门票

### 八达岭长城
- 门票：旺季40元，淡季35元
- 建议游览：半天
- 明长城中保存最完好的一段，"不到长城非好汉"即指此处
- 提示：可乘S2线火车或旅游专线前往，建议早出发避开人流

### 颐和园
- 门票：旺季30元，淡季20元（联票60/50元）
- 建议游览：3小时
- 中国现存最大的皇家园林，以昆明湖、万寿山为主体
- 提示：推荐从东宫门进，游览长廊、佛香阁、昆明湖

### 天坛公园
- 门票：15元（联票34元）
- 建议游览：2小时
- 明清两代皇帝祭天、祈谷的场所，祈年殿为标志性建筑
- 提示：清晨有很多市民健身，可感受老北京生活气息

### 南锣鼓巷
- 门票：免费
- 建议游览：2小时
- 北京最古老的街区之一，胡同与四合院风貌
- 提示：周边有很多特色小店和咖啡馆，适合漫步

## 特色美食
- 北京烤鸭：全聚德、便宜坊为代表，皮脆肉嫩，配薄饼葱丝甜面酱
- 炸酱面：老北京家常面食，黄酱肉丁浇头
- 豆汁儿配焦圈：老北京传统早餐，味道独特，外地人需适应
- 卤煮火烧：猪肠猪肺火烧煮制，平民美食
- 涮羊肉：铜锅清汤涮羊肉，蘸麻酱小料

## 交通建议
- 市内交通：地铁覆盖主要景点，推荐办理一卡通或使用乘车码
- 机场到市区：首都机场快轨25元直达东直门；大兴机场线35元
- 长城方向：推荐北京北站乘S2线火车，约1.5小时
