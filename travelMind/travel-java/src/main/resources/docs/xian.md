# 西安旅游指南

## 城市概况
西安陕西省省会，十三朝古都，丝绸之路起点，中华文明重要发祥地。最佳旅游季节为春秋两季（3-5月、9-11月），夏季炎热，冬季寒冷干燥。

## 核心景点

### 秦始皇兵马俑博物馆
- 门票：120元
- 建议游览：半天
- 世界第八大奇迹，秦代陶俑军阵，震撼人心
- 提示：建议请讲解员或租讲解器，否则只能看陶俑不懂历史；从西安站乘游5(306)路约1小时

### 西安城墙
- 门票：54元
- 建议游览：2小时
- 中国现存规模最大、保存最完整的古代城垣，可骑行或步行环游
- 提示：推荐傍晚骑行一圈（约14公里），夜景灯光很美；南门(永宁门)登城最佳

### 大雁塔
- 门票：40元（登塔30元另收）
- 建议游览：2小时
- 唐代玄奘法师译经之地，西安地标，周边是大雁塔北广场音乐喷泉
- 提示：晚上9点喷泉表演免费观看，场面壮观

### 回民街
- 门票：免费
- 建议游览：2小时
- 西安著名美食街，清真风味小吃聚集
- 提示：推荐老孙家泡馍、贾三灌汤包、肉夹馍、甑糕

### 华清宫
- 门票：120元
- 建议游览：3小时
- 唐代皇家温泉行宫，杨贵妃沐浴之地，《长恨歌》实景演出在此
- 提示：《长恨歌》演出需另购票（约298元起），强烈推荐

## 特色美食
- 肉夹馍：腊汁肉夹白吉馍，"中国式汉堡"
- 羊肉泡馍：掰馍后羊肉汤煮制，西安代表美食
- biangbiang面：宽如裤带的手工面，油泼或蘸水
- 凉皮：麻酱凉皮、秦镇凉皮，酸辣爽口
- 甑糕：糯米红枣蒸制，甜糯
- 葫芦鸡：西安传统名菜，皮酥肉嫩

## 交通建议
- 市内交通：地铁覆盖主要景点，公交发达
- 兵马俑方向：西安火车站东广场乘游5(306)路，直达兵马俑
- 华清宫方向：同游5路，先到华清宫再到兵马俑，建议一并游览
