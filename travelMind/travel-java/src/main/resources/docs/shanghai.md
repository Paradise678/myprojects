# 上海旅游指南

## 城市概况
上海是中国最大的经济中心城市，国际化大都市，融合了东西方文化。最佳旅游季节为春秋两季（3-5月、9-11月），气候温和。夏季炎热潮湿，冬季湿冷。

## 核心景点

### 外滩
- 门票：免费
- 建议游览：2小时
- 上海标志性景观，黄浦江畔52幢风格各异的万国建筑博览群
- 提示：夜晚灯光璀璨最美，对岸陆家嘴天际线（东方明珠、上海中心、金茂大厦）尽收眼底

### 上海迪士尼度假区
- 门票：475元起（旺季更高）
- 建议游览：1天
- 中国大陆首座迪士尼主题乐园，拥有全球最高的奇幻童话城堡
- 提示：建议提前下载官方APP查看排队时间，热门项目需早去或买尊享卡

### 豫园
- 门票：40元
- 建议游览：2小时
- 明代古典园林，江南园林代表，周边是城隍庙和豫园商城
- 提示：可顺路逛城隍庙小吃广场，品尝南翔小笼包

### 东方明珠
- 门票：199元起（不同观光层价格不同）
- 建议游览：2-3小时
- 上海地标建筑，高468米，可俯瞰黄浦江两岸
- 提示：259米全透明悬空观光廊值得体验

### 田子坊
- 门票：免费
- 建议游览：2小时
- 由石库门里弄改造的创意园区，艺术工作室、特色小店聚集
- 提示：适合拍照和淘文创产品

## 特色美食
- 南翔小笼包：皮薄馅大汤汁多，豫园南翔馒头店最正宗
- 生煎包：底部煎至金黄酥脆，汤汁丰盈，大壶春、小杨生煎为代表
- 本帮红烧肉：浓油赤酱，甜咸适口
- 蟹粉豆腐：秋季限定，大闸蟹蟹黄烧制
- 葱油拌面：上海经典面食，葱油香浓郁

## 交通建议
- 市内交通：地铁网络发达，推荐使用大都会APP或乘车码
- 浦东机场到市区：地铁2号线约70分钟，磁悬浮8分钟到龙阳路（50元）
- 虹桥机场/火车站：地铁2号线、10号线直达市区
