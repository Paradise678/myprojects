# 杭州旅游指南

## 城市概况
杭州是浙江省省会，长江三角洲中心城市之一，以西湖闻名于世，素有"人间天堂"的美誉。最佳旅游季节为春季（3-5月）和秋季（9-11月），气候宜人。

## 核心景点

### 西湖
- 门票：免费
- 建议游览：半天至一天
- 西湖十景包括：苏堤春晓、曲院风荷、平湖秋月、断桥残雪、花港观鱼、柳浪闻莺、三潭印月、双峰插云、雷峰夕照、南屏晚钟
- 推荐游览路线：断桥残雪 → 白堤 → 苏堤 → 花港观鱼 → 雷峰塔
- 提示：雷峰塔登塔需另购门票40元，可俯瞰西湖全景

### 灵隐寺
- 门票：75元（含飞来峰景区）
- 建议游览：3小时
- 杭州最古老的佛教寺院，始建于东晋咸和元年（326年）
- 提示：飞来峰石刻造像是国宝级文物，值得细看

### 西溪国家湿地公园
- 门票：80元
- 建议游览：3小时
- 国内首个国家湿地公园，可乘船游览水网
- 提示：建议秋季前往，芦苇荡景色最佳

### 宋城
- 门票：320元（含《宋城千古情》演出）
- 建议游览：半天
- 大型宋文化主题公园，《宋城千古情》演出为必看项目

### 河坊街
- 门票：免费
- 建议游览：2小时
- 杭州历史文化街区，可品尝定胜糕、葱包桧等小吃

## 特色美食
- 西湖醋鱼：酸甜口味，选用西湖草鱼
- 东坡肉：色泽红亮，肥而不腻
- 龙井虾仁：用龙井茶炒制的虾仁，清香鲜美
- 叫花童鸡：用荷叶包裹烤制的整鸡
- 片儿川：杭州特色面食，雪菜笋片肉丝浇头

## 交通建议
- 市内交通：地铁1/2/4/5号线覆盖主要景点，推荐办理杭州地铁乘车码
- 西湖周边：建议步行或租用共享单车，沿途风景优美
- 从杭州东站到西湖：地铁1号线到龙翔桥站，约20分钟
